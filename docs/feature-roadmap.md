# 博客功能规划

记录日期：2026-09-16

本文记录后续可实现的功能，方便查阅与选择开发任务。优先级为初步建议，可按实际需求调整；以下条目均为候选功能，不代表已实现。

## 高优先级

| Feature | 功能说明 | 初步范围 |
| --- | --- | --- |
| 草稿自动保存与恢复 | 降低刷新、意外关闭或断网造成的内容丢失风险 | 先实现本地定时保存、按文章区分草稿、恢复确认和保存成功后清理；后续考虑服务端同步 |
| Markdown 导入/导出 | 导入已有文章，导出用于备份和迁移 | 支持正文、标题、列表、引用、链接和代码块，保留 Mermaid 源码；导入时提示不支持的内容 |
| 文章目录 | 根据文章标题生成目录，快速跳转到对应章节 | 为标题生成稳定且不重复的锚点，支持多级目录与移动端折叠 |
| 图表放大与导出 | 改善复杂 Mermaid 图表的查看与复用体验 | 支持放大查看、关闭或 Escape 返回、导出 SVG；PNG 导出作为后续扩展 |
| 代码语法高亮 | 改善技术文章的代码阅读体验 | 支持 Java、Go、JavaScript 等语言，增加复制按钮；普通代码高亮与 Mermaid 渲染分开处理 |
| 标签点击筛选 | 从文章标签发现相关内容 | 点击详情页标签跳转到文章列表，列表从 URL 初始化筛选条件，支持分享和浏览器前进/后退 |

## 中优先级

| Feature | 功能说明 | 初步范围 |
| --- | --- | --- |
| 写作快捷操作 | 减少工具栏操作，提高内容插入效率 | 输入 `/` 打开插入菜单，支持标题、普通代码块、图表和引用，并支持键盘选择 |
| 文章修订历史 | 查看历史版本并恢复误修改的文章 | 保存修订记录，提供版本列表、差异对比与恢复操作；恢复时保留当前版本 |
| 发布前预览 | 保存前检查与阅读页一致的排版效果 | 复用阅读页正文渲染组件，预览文字、代码和 Mermaid，不改变发布状态 |
| 系列文章 | 将相关文章组织成连续阅读的系列 | 设置系列与排序，展示系列目录、上一篇和下一篇 |
| 阅读进度与预计时长 | 帮助读者了解文章长度与当前阅读位置 | 展示字数、预计阅读时间与正文阅读进度条，明确代码块和图表的计数方式 |
| 定时发布 | 草稿到指定时间自动发布 | 设置发布时间和时区，支持取消或修改，记录执行结果，避免重复发布 |
| 全文搜索结果高亮 | 在搜索结果中快速定位匹配内容 | 展示匹配关键词和上下文；输出安全的高亮内容，区分关键词匹配与语义搜索 |
| RSS 订阅 | 让读者通过订阅工具获取新文章 | 仅输出已发布文章，提供稳定文章标识、链接、发布时间与摘要 |
| 回收站 | 恢复误删除的文章 | 软删除、回收站列表、恢复和明确确认后的永久删除；回收站文章不进入公开搜索和推荐 |

## 低优先级

| Feature | 功能说明 | 初步范围 |
| --- | --- | --- |
| Graphviz / Vega 渲染 | 扩展 DOT 关系图和数据图表 | 复用现有图表渲染器注册表，按需加载依赖，增加白名单、安全校验和失败降级；不开放任意代码执行 |

## 建议实施顺序

1. 草稿自动保存与恢复。
2. 文章目录。
3. 代码语法高亮。
4. 图表放大与导出（先 SVG，后 PNG）。
5. 标签点击筛选。

这五项优先改善日常写作可靠性与阅读体验。完成后，再按需求选择 Markdown 导入/导出、发布前预览或文章修订历史。

## 开发约定

- 每项功能实施前核对已有实现，明确本次范围和验收条件。
- 保留现有文章数据兼容性，以及正文、普通代码与多个图表的混排能力。
- 涉及草稿、版本、删除或发布状态时，明确权限、恢复和清理策略。
- 按项目约定，开发期间仅进行静态检查，完整任务结束后统一进行构建与测试；用户明确要求时例外。
